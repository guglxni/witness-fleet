# Submission brief and AI-use disclosure

## Project

**Witness Fleet — Evidence before motion.** A three-robot MuJoCo mission uses FalkorDB as its connected operational record for task dependencies, claims, policy provenance and outcomes. A corridor can be physically clear while a courier still lacks permission; a source-linked configured release and fresh courier evidence must precede delivery.

## Tracks

- **Primary: Track 01 — Agents That Act on Connected Data.** FalkorDB relationships resolve governing restrictions, permissions, dependencies and evidence before deterministic authorization and native simulation actions. Connected data changes task eligibility and the action path.
- **Secondary: Track 02 — Agent Memory and Coordination.** Shared operational task state, dependencies, claim fences, retained command/outcome history and fail-closed recovery across a centrally coordinated simulation. This is not decentralized swarm consensus.
- **Secondary: Track 03 — Company Brain.** Synthetic decisions, owners, restrictions and releases linked to exact retained source spans. This is a scoped policy workflow, not a general enterprise assistant.

Track 01 is the main claim. Tracks 02 and 03 describe supporting mechanisms, not separate general-purpose products. The participant must choose the intended tracks in the organizer form; this document is not submission confirmation.
