# Submission brief and AI-use disclosure

## Project

**Witness Fleet — Evidence before motion.** A three-robot MuJoCo mission uses FalkorDB as its authority and coordination layer. A corridor can be physically clear while a courier still lacks permission; a source-backed release and fresh courier evidence must precede delivery.

## Tracks

- **Primary: Track 01 — Agents That Act on Connected Data.** Graph queries resolve governing restrictions, permissions, dependencies and evidence before deterministic authorization and native actions.
- **Secondary: Track 02 — Agent Memory and Coordination.** Shared operational graph, claim fences, task dependencies, retained command/outcome history and fail-closed restart handling. This is centrally coordinated simulation, not decentralized swarm consensus.
- **Secondary: Track 03 — Company Brain.** Synthetic company documents, decisions, owners, restrictions and releases are linked to exact retained source spans. This is a scoped policy workflow, not a general enterprise assistant.

The participant must select the intended tracks in the submission form; listing them here is not submission confirmation.
