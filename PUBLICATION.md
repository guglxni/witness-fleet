# Publication scope

This repository publishes the executable Witness Fleet application, tests, original specifications, editable diagram sources, website, deployment automation, and produced demonstration-media provenance. It is a clean source publication, not a mirror of the development workspace.

Excluded by design: third-party full-text research captures/PDFs, vendor clones, local test/capture journals and graph databases, machine-specific reports, environment files, credentials, dependency directories, and bulk render caches. Original development history and retained evidence remain local and are not deleted. Source citations and pinned dependency references preserve reproducibility without redistributing unrelated source archives.

The normal recorded SC-001 mission and restart/unknown-outcome tests prove different things. The film does not portray crash recovery if no crash occurred in that capture. The configured demonstration owner is not an authenticated human or production IAM identity. The bounded public demo is simulation-only and cannot control hardware.

The public code is not a certified robotics safety system. Exact acceptance applies to the tested revision and scenario, not every aspirational specification or optional model provider.
